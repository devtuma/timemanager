## 📋 Passos para Ativar o GitHub Pages

### 1️⃣ Acesse o Repositório no GitHub

Vá para:
```
https://github.com/devtuma/timemanager
```

### 2️⃣ Acesse as Configurações

1. Clique na aba **⚙️ Settings** (no topo do repositório)
2. No menu lateral esquerdo, clique em **📄 Pages**

### 3️⃣ Configure o GitHub Pages

1. Em **Source**, clique no dropdown **"None"**
2. Selecione a branch: **`claude/timer-manager-app-011CV5xFEyMuih3XnBptvcwB`**
3. Deixe a pasta como **`/ (root)`**
4. Clique em **💾 Save**

### 4️⃣ Aguarde a Publicação

- O GitHub vai começar a publicar automaticamente
- Aguarde **2-5 minutos**
- Uma mensagem verde aparecerá com o link

### 5️⃣ Acesse seu App!

Após a publicação, seu app estará disponível em:
```
https://devtuma.github.io/timemanager/
```

## ⚠️ Importante sobre o Modo GitHub Pages

No GitHub Pages, o app funciona em **modo local**:
- ✅ Todos os recursos funcionam
- ✅ Dados salvos no navegador (localStorage)
- ⚠️ Dados não sincronizam entre dispositivos
- ⚠️ Limpar cache do navegador = perder dados

### 🌐 Para Sincronização em Nuvem

Se quiser sincronização entre dispositivos, faça deploy na **Hostinger** seguindo o guia **INSTALL.md**.

## 🆘 Problemas?

### GitHub Pages não aparece nas configurações
- Certifique-se que o repositório é **público**
- Vá em Settings → Geral → Visibility → Public

### Link não funciona após 5 minutos
- Aguarde mais alguns minutos
- Verifique se a branch está correta
- Tente acessar: `https://devtuma.github.io/timemanager/index.html`

### Erro 404
- Certifique-se que salvou as configurações
- Aguarde mais 2-3 minutos
- Force refresh: Ctrl+F5 (Windows) ou Cmd+Shift+R (Mac)
